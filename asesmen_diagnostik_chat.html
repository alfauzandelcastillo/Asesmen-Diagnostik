📖 Panduan Praktis 4 Langkah Menyiapkan Google Spreadsheet:

1 Buat Spreadsheet Baru

Buka sheets.new di browser untuk membuat Google Spreadsheet baru. Beri judul misalnya: "Rekap Asesmen Diagnostik SMA".

2 Buka Menu Ekstensi > Apps Script

Di bagian menu atas Google Spreadsheet, klik Ekstensi (Extensions) lalu pilih Apps Script. Jendela editor kode akan terbuka.

3 Tempelkan Kode Script di Bawah Ini

Hapus tulisan bawaan function myFunction() {}, lalu tempelkan seluruh kode berikut dan klik ikon Simpan 💾:

4 Deploy sebagai Web App & Salin URL
  1. Di pojok kanan atas Apps Script, klik tombol Deploy (Terapkan) > New deployment (Penerapan baru).
  2. Klik ikon roda gigi ⚙️ di sebelah kiri, pilih Web app (Aplikasi Web).
  3. Pada kolom Execute as, pilih: Me (email Anda).
  4. Pada kolom Who has access, WAJIB pilih: Anyone (Siapa saja) agar siswa bisa mengirim jawaban tanpa harus login.
  5. Klik Deploy, lalu beri izin akun Google Anda (jika ada peringatan keamanan, klik Advanced / Lanjutan > Buka script (tidak aman)).
  6. Salin Web app URL (yang berakhiran /exec), lalu tempelkan ke kolom input di atas!
